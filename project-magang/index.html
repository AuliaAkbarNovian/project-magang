Rencana Kerja Aplikasi Enterprise-Lite

Enterprise-Lite adalah aplikasi internal untuk membantu perusahaan mengelola tugas dan mencatat waktu kerja karyawan secara sederhana.

Fitur Utama

1. Auth / Login

  • Pengguna dapat login menggunakan username dan password.
  • Sistem membatasi akses hanya untuk pengguna yang terdaftar.
  • Setelah login, pengguna diarahkan ke halaman dashboard.

2. Dashboard Ringkasan

  • Menampilkan jumlah total tugas.
  • Menampilkan tugas yang sedang dikerjakan.
  • Menampilkan tugas yang sudah selesai.
  • Menampilkan ringkasan waktu kerja yang telah dicatat.

3. CRUD Tasks

  • Create: pengguna dapat menambahkan tugas baru.
  • Read: pengguna dapat melihat daftar tugas.
  • Update: pengguna dapat mengubah data tugas.
  • Delete: pengguna dapat menghapus tugas yang tidak diperlukan.

4. Time Logs

  • Pengguna dapat mencatat waktu mulai dan selesai pengerjaan tugas.
  • Sistem menghitung durasi waktu kerja.
  • Data waktu kerja dapat digunakan sebagai laporan produktivitas.

Tujuan Pengembangan

Tujuan pembuatan aplikasi ini adalah untuk mempermudah pemantauan pekerjaan, meningkatkan kedisiplinan dalam pencatatan waktu, dan membantu tim bekerja lebih teratur.
